# DAA Assignment 4A – Java implementation companion

**Important academic note:** The supplied Assignment 4A PDF explicitly says this is a design/pseudocode assignment and programming code will not be accepted as pseudocode (pages 1 and 16). These Java files are for learning, checking logic, and later practice only. Do not submit Java code in place of the required SIMATS pseudocode.

## Included programs
1. `Task1_FractionalKnapsack.java` – fractional knapsack greedy ratio.
2. `Task2_JobSequencing.java` – job sequencing with deadlines.
3. `Task3_Knapsack01.java` – 0/1 knapsack DP and item reconstruction.
4. `Task4_WordBreak.java` – corrected Word Break DP (`dp[j]` must be true).
5. `Task5_ShortestPaths.java` – Dijkstra, Bellman-Ford, reachable negative-cycle detection, Floyd-Warshall.
6. `Task6_WeightedIntervalScheduling.java` – weighted interval scheduling DP for the energy-aware job challenge.

## Run (Windows PowerShell, JDK 8+)
```powershell
cd src
javac *.java
java Task1_FractionalKnapsack
java Task2_JobSequencing
java Task3_Knapsack01
java Task4_WordBreak
java Task5_ShortestPaths
java Task6_WeightedIntervalScheduling
```
